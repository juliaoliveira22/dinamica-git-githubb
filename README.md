# Dinâmica de Grupo: Git e GitHub

## Objetivo
Aprender a utilizar Git e GitHub para compartilhar arquivos e acompanhar alterações em um projeto.

## Ferramentas
- Git
- GitHub
- Visual Studio Code

## Comandos Git
- git clone: copia um repositório.
- git status: verifica as alterações.
- git add .: prepara os arquivos.
- git commit -m "mensagem": registra as alterações.
- git push: envia alterações ao GitHub.
- git pull: atualiza o repositório local.

## Como executar
Acesse o repositório pelo GitHub e consulte as instruções e os comandos acima.
